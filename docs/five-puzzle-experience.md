# 5問で「もう1問」を検証する

これは次に作る試作の設計・制作条件。新しい5問の盤面や改善版アプリはまだ未制作。原版と既存の検証結果は保持する。

## 準備と5問の役割

初見には本編と別の短い練習を3つ置く。0／満数と入力、水平の連動、下方向の伝播を順に体験させる。説明を閉じた後に別配置で同じ手筋を使えるかを見る。学習済みなら練習を飛ばせる。

| 問 | 期待する楽しさ | 制作条件 | 観察点 |
| --- | --- | --- | --- |
| 1 | すぐ気づけて、触り始められる | 小さな入口の後に水平か下方向を使う。残数だけで全て終わる問題にしない | 説明なしで入り口を見つけるか |
| 2 | 前の気づきが別の形でも使える | 同じ手筋・近い難度で配置と推理の順を変える | 暗記でなく理解しているか |
| 3 | ひとつ分かると、続けて分かる | 短い推理と数マスの入力が交互に起こる。長い塗り区間を避ける | 連鎖の気持ちよさがあるか |
| 4 | 少し見方を変える発見 | 水槽の幅と残数を一度比較する。推測不要。前問より大幅に重くしない | 面白い一呼吸か、突然の壁か |
| 5 | 同じ手触りで気持ちよく終わる | 新ルール・ボス問題なし。通常の難度帯で完結 | 余韻と継続意思 |

問ごとの難度上昇を目的にしない。3〜5問の順番を変えた条件も試し、5問目が簡単だから続けたのかを区別する。任意の6問目は同難度の別問。特別報酬・予告で続行を誘導しない。

## 問題の受入条件

- 全領域が正しく分割され、水位制約の下で一意解。検証器で確認する。
- 保存解を参照しない推論ログを残す。説明できない仮置きの連続を使わない。
- 1問目から水槽固有の手筋が実際に必要か、残数だけの推論でも解けないかを確認する。これは任意の人間の別解法が存在しないという証明ではない。
- 1回の発見の後に短い入力があり、その入力が次の発見につながる。制作時に想定手順と入力数を記録し、試遊時の手順と比較する。
- 形や色の違いだけでなく、見る順・手筋の組合せを変える。複雑な領域を増やすことを多様性の代わりにしない。

原版の1・2問は入力練習の参考、3問目の「残り1に横2マスは入らない」は説明ヒントの参考にする。原版の難度順をそのまま新セットの正解にしない。

## 試遊手順

1. 最初は依頼者本人で試す。本人が目指す「触る気持ちよさ」に合わなければ先に直す。続いて初見5人程度で理解の欠落を調べる。少人数から市場全体の継続率を推定しない。
2. 練習後の5問を自分のペースで遊ぶ。途中終了可。プレイ中に「楽しいですか」と繰り返し聞かず、終わってから気づいた瞬間・退屈な区間を振り返る。
3. 5問終了時に同等の見た目で「もう1問」「今日はここまで」を表示。促さず、選択と任意の6問目の完了を記録する。時間の都合で終了した場合も別に記録する。
4. 触覚は同じ実機・音設定で、振動なしと弱／標準を比較する。条件の順を入れ替え、同じ問題の記憶効果を避ける同難度セットを用意する。10分程度続けた疲労も確認する。
5. 終盤補助は触覚設定を固定して別の比較にする。全手動と「残りの乾燥をまとめて完了」で、速さだけでなく満足感を比較する。
6. 数日後、通知や報酬の催促なしで再び遊びたいかを確認する。実際の再プレイと、質問への好意的な返答を区別する。

## 記録と判断

| 指標 | 意味・判定への使い方 |
| --- | --- |
| 任意6問目の開始・完了 | 主指標。本人が自発的に選び、その理由が「操作または推理が気持ちよい」と一致するか。人数と理由を併記 |
| 快さ・退屈・疲労（各5段階） | 水、乾燥、終盤について別に聞く。総合点で問題を隠さない |
| 気づき→入力→次の気づき | 操作の間と本人の振り返りを対応させる。無操作時間を自動的に退屈・思考と断定しない |
| 推理が終わった後の入力 | 本人がどこで答えを把握したかを振り返りで確認。推定時間と主観的負担を併記 |
| ヒント・誤入力・取り消し | 理解不足、操作ミス、探索行動を区別する。少なければ楽しいとは限らない |
| 数日後の再プレイ | 日課としての可能性。短い試験だけで長期継続を実証したとしない |

30問へ進む暫定条件: 本人が実機で任意の続行を選び、繰り返す入力の快さを説明できる。初見では5人中4人程度が練習後のルールを理解し、複数人に同じ退屈や不快感が集中しない。達成しても商品性の証明ではなく次の実験へ進む根拠とする。未達のときは該当部分だけ改訂し、同じ条件で再評価する。

分岐: 「解くのは楽しいが塗りが面倒」なら終盤補助。「触るのは快いが退屈」なら短い水槽推論を増やす。「毎回詰まる」なら導入・問題構成・説明ヒント。「振動が疲れる」なら弱さ・長さ・重なりを直す。両方の価値が弱ければ量産せず設計を再考する。
