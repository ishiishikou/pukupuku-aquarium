# 本編代表1問：5×5試遊版

Issue #3 の小さな実装スライス。PR #1 の設計・原版には変更を加えない。

## 入口

[単問HTML](../prototype/playable/index.html)をダウンロードして、Edge/Safari/Chromeで開く。ローカルサーバー不要。改善版専用の保存キーを使用し、原版と干渉しない。単問のため「もう1問」はまだ提供しない。音・ブラウザ振動は補助演出で、iPhoneの実機触覚評価ではない。

## 問題データ

[representative-5x5.json](../examples/representative-5x5.json)。行: 0/3/4/3/5、列: 2/2/4/4/3。
水槽区画（同一の文字は一つの連結水槽）:

```text
ABBCC
ADBCC
ADDDE
FFDDE
FFGGG
```

**数学的確認**: 各水槽の全水位候補2592通りを、保存解を探索条件に用いずに全列挙して唯一解1通り。各水槽は連結。行・列の0/満数と残数を埋めるだけの伝播では9マス残り、水槽固有の水平連動が必要。全探索による一意性と、人間が気持ちよく解けることは別判定。

## 保存解を参照しない推理と入力の例

座標は1始まり。ユーザーは各段で自分で入力する。順序は推奨例で強制ではない。

1. **入口**: 行1は0なので r1c1〜5=×。行5は5なので r5c1〜5=水。
2. **残数から水を広げる**: 列3・列4は各4。1行目が乾燥なので r2〜5c3とr2〜5c4が水（既入力を除き各3マス）。
3. **水槽の水平連動**: 水槽Cのr2c4が水なので同じ高さのr2c5も水。水槽Dのr3c3が水なので同じ高さのr3c2も水。
4. **数字から次の入力**: 行2は水3マスに達したのでr2c1,2=×。列2はr3c2,r5c2が水で合計2に達するためr4c2=×。同じ水槽Fのr4c1も×。
5. **残りの連鎖**: 行4はあと1だからr4c5=水。列1はあと1だからr3c1=水。列5は3マスの水がそろいr3c5=×。全25マス確定。

この順に推測は不要。解は以下（1=水、0=乾燥）。

```text
00000
00111
11110
00111
11111
```

## 検証と体験を別に判定

- **数学**: `python scripts/verify.py examples/representative-5x5.json` で一意・保存解一致、`python -m unittest discover -s scripts -p 'test_*.py'` で回帰と残数のみ9未解決を検査。
- **実装**: 水／×モード、同じモードで再タップすると未確定、取り消し、理由付きの次の一手ヒント、数字の水数一致表示、明白な矛盾表示、全25マス・全制約成立のクリア判定、ローカル保存、終了・再挑戦を確認。
- **楽しさは未検証**: 「気づき→2〜6マス入力→次の気づき」を自然に感じたか、水の操作と×の操作の快さ、最後の塗りが負担かを本人の試遊で確認する。表示時間、速さ、一意解、Pythonテスト成功から楽しいと断定しない。
- **iPhoneの触覚**: WebのVibration APIは対応状況が異なる。触覚を実証したとは記録しない（Issue #4）。
- **ブラウザ動作**: ブラウザでの実操作確認結果は実施後に追記する。静的レビューは実機検証の代わりではない。
