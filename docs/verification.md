## 全10問の独立検査

抽出元はHTMLの `const puzzles=` に続くJSON配列。JavaScriptを実行せずJSONとして読み、長方形領域をラベル盤へ変換した。領域の範囲・重複・欠落、数字、保存解の重複と範囲を検査。全問givensは空。正解配列waterから制約を作らず、領域と行列数字だけで全水位組合せを列挙し、最後にwaterと照合した。

規則は今回の実行順で使用したもので、最小手筋や必要難度の証明ではない。ログ項目数は複数セルの一括確定や候補除外を含み、タップ数・人の思考回数ではない。

推論器は残数による確定、同水槽の水平・上下伝播、単一行列における他水槽の最小／最大寄与からの候補除外のみを用いる。保存解・全探索結果を参照せず、仮置き・バックトラックもしない。10問とも全マス確定し、別の全探索結果と一致。[全手順](original-logic-traces.md)を残した。人がその手筋を自然に発見できるかは別検証。

## 再現と成果物

Python 3.11以上、標準ライブラリのみ。assertで検査するため `python -O` は使用しない。

```sh
python scripts/audit_original.py
python -m unittest discover -s scripts -p 'test_*.py'
```

8テスト成功。全10問の確定セルを全探索解と照合し、複数解で勝手に推測しないこと、矛盾盤を完了扱いしないことも確認。矛盾盤の負例で推論器の最終整合検査不足を検出し、検証コードを修正して再実行した。原版HTMLは変更していない。

前回の4×4新規例題も維持。288水位組合せと別実装による65,536セル配置の全探索で一意性確認済み。セル全列挙は元の10問には適用していない。水位列挙は200万候補を超えると未検証エラー。今回全問上限内で終了。
