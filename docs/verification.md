## 再現

```sh
python scripts/verify.py examples/tutorial.json
python -m unittest discover -s scripts -p 'test_*.py'
```

## 検査の定義と限界

入力は領域IDの長方形配列、行列の整数ヒント、任意の保存解（1=水、0=乾燥）。各領域は上下左右に連結し、全マスがちょうど1水槽に所属する。保存解を探索の制約にせず、各水槽の全水位を列挙して数字との一致を確認し、その後に保存解と照合する。

同じ水槽にk種類の行があれば候補は空を含むk+1通り。完全な候補空間の直積を検査するので探索を完了した場合は解数が厳密。200万候補を超えると未検証としてエラーにする。現段階では小問題用であり、大量生成用の高速探索・人間向け推論器・水路制約は未実装。

セル全列挙の対照検査は小問題専用。元の5×5〜6×6へ無条件に流用しない。水位列挙は入力の構造検査を共有するが、対照検査の水位条件自体はセル間の水平一致と上下の不等式で別実装している。
