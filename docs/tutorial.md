# 推奨ルールの小問題と推理手順

本レビューで新規作成した説明用問題。引き継ぎ版10問には含まれない。これは難度調整済みの通常問題ではない。

同じ文字が同じ水槽。異なる文字の境目が壁。行は上から、列は左から数える。同じ水槽の同じ行は同じ状態、水より下の同じ水槽は全て水。水槽は空でも満水でもよい。

```text
        列 3 3 1 2
           ┌───┬───┐
行 0       │A A│B B│
           │   ├───┤
行 2       │A A│C C│
           ├───┼─┐ │
行 3       │D D│E│C│
           ├───┤ │ │
行 4       │F F│E│C│
           └───┴─┴─┘
```

1. 1行目は0なので全て乾燥。4行目は4なので全て水。
2. 1列目は3。1行目は乾燥なので、残る2・3・4行目は全て水。
3. 2行1列のAが水なので、同じ水槽・同じ高さの2行2列も水。
4. 2行目の必要数2が埋まったので、2行3・4列は乾燥。
5. 3行1列のDが水なので、3行2列も水。
6. 3列目は1。4行3列がすでに水なので、3行3列（E）は乾燥。
7. 3行目は3必要。Dの2マスが水、Eは乾燥なので、残る3行4列（C）は水。
8. 全マス確定。列は3,3,1,2、水槽CとEも下からたまり、全条件に一致する。

```text
× × × ×
水 水 × ×
水 水 × 水
水 水 水 水
```

全ての手順が必然で分岐しないため、これは存在する解を示すと同時に一意性の証明でもある。[JSONデータ](../examples/tutorial.json)を検証器でも確認済み。初見の説明効果は人による試遊待ち。
